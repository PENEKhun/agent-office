# 아이콘 출처

- `anthropic.svg`, `openai.svg`, `googlegemini.svg`: Simple Icons SVG. Anthropic과 Gemini 파일은 simple-icons 15.0.0, OpenAI 파일은 OpenAI 아이콘이 포함된 simple-icons 15.0.0에서 받았다. Simple Icons 아이콘 파일은 CC0로 배포되며, 각 로고와 상표는 해당 권리자에게 속한다.
- `opencode.svg`: opencode.ai의 공식 파비콘을 배지에 쓰도록 배경을 없애고 색을 반전해 단순화한 것이다. 로고와 상표는 해당 권리자에게 속한다.
